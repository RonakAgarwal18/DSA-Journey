# TUF-A2Z — TakeUForward platform solutions

Problems solved on the **TakeUForward platform** (not on LeetCode) live here, pushed manually at the day's close-out. LeetCode solutions are synced automatically by LeetHub v2 and land in the repo root — don't duplicate them here.

## Structure

One folder per A2Z step:

```
TUF-A2Z/
  step-01-basics/
  step-02-sorting/
  step-03-arrays/
  ...
  step-18-advanced-strings/
```

File name = problem slug, e.g. `count-digits.cpp`. Add the step folder when you solve its first TUF-platform problem.

## Rules

- Only problems actually solved on the TUF platform.
- Paste in the code you submitted — not a rewritten version.
- One commit per day at close-out is fine; the LeetCode push already carries the day's streak.
